## About the project

This is a personal project which explores video game industry data to help better understand sales performance and market trends. I did this with the intention to then present research, findings and actionable insights to a group of stakeholders from a fictional game developer business to help solidify business goals and improve sales.

Key questions which needed to be answered:
- Which year performed the best based on unit sales?
- What was the split between the varying game genres available?
- Overall, which game genre performed the best based on unit sales?

The video games industry was chosen as the focus for this project as this is an area that has always fascinated me. I enjoy playing video games myself and I've always found it interesting to see the variety in games available over the years, as well as understanding how each perform and what influences best-selling games across the market.
